### **ITEM #1 — Cascaded Selective Evaluation**

**Integration Point:** §8.5 (G-study, judge replication protocol)

**Current State:** 
```python
# src/trait/judge/replication.py
for neuron in neurons:
    for rep in range(N_REPLICATES):  # Fixed N at boundaries
        judge_output = judge.score(neuron, transcript)
```

**Change:** Replace fixed-N with disagreement-triggered cascade.

```python
# Pseudocode
def cascaded_replicate(neuron, transcript, target_phi):
    replications = []
    for initial_rep in range(3):  # Initial 3 replications
        replications.append(judge.score(neuron, transcript))
    
    disagreement = variance(replications)  # Query signal
    if disagreement > threshold(target_phi):
        # Escalate to K additional passes
        for extra_rep in range(K):
            replications.append(judge.score(neuron, transcript))
    
    return median(replications), confidence_interval(replications)
```

**What It Fixes:**
- Fixed-N wastes compute on high-confidence interior scores
- No statistical guarantee of quadrant-flip coverage
- Cascaded approach: only boundary-ambiguous cases escalate → compute savings 30–50% while reliability improves

**Data Requirement:** None (runs on existing judge)

**Gate:** Human IRR (#5) must establish Φ target first

**Rung:** MEASURABLE (once G-study clears with ≥30 subjects)

**Source:** Jung et al. (ICLR 2025) — Trust or Escalate

**Migration:** None (code-only change)

**Integration Point:** §6 (judge prompt design)  
**Files Affected:** `src/trait/judge/prompt.py`, `src/trait/judge/client.py`, `src/trait/judge/rubric_bank.py` (new)

**Current State:**

```python
prompt = f"Score {len(neurons)} neurons on this transcript..."

```

**Change:** One independent call per neuron; constrain scales; add leniency correction.

```python
# One call per neuron
for neuron in NEURONS_107:
    if neuron.scale_type == "ordinal":
        # Constrain to 3-5 levels with behavioral anchors
        rubric = RUBRIC_BANK[neuron.id]  # e.g., "C1-Sense-Making"
        response = judge.score(
            neuron_id=neuron.id,
            transcript=transcript,
            rubric=rubric,
            scale=["unmet", "emerging", "met", "exceeded"]  # 4 levels max
        )
    elif neuron.scale_type == "binary":
        response = judge.score(
            neuron_id=neuron.id,
            transcript=transcript,
            rubric=rubric,
            scale=["unmet", "met"]  # Binary where definition permits
```

**What It Fixes:**

- Central-tendency bias (broad scales invite compression)
- Leniency bias (judge defaults to positive without negative criteria)

**Gate:** CE sign-off on API budget + Item #5 (rubric anchoring basis)

**Rung:** MEASURABLE

**Source:**

### **ITEM #3 — IRT Diagnostics on Judge Output**

**Integration Point:** §8.5 (new sub-section, post-G-study)  
**Files:** `src/trait/validation/judge_irt.py` (new)

**Measurement Goal:** Decompose judge error into two sources:
1. **Noise** — inconsistent scoring (fix the rubric)
2. **Bias** — systematic divergence from human judgment (fix the prompt)

**Method:** Fit Graded Response Model to judge replications.

```python
# Pseudocode
from sklearn.mixture import GaussianMixture  # or Stan/brms

def diagnose_judge_reliability(judge_replications, human_gold):
    """
    judge_replications: dict[neuron_id] -> list[scores from K replications]
    human_gold: dict[neuron_id] -> consensus human label
    
    Output: per-neuron discrimination (a) and difficulty (d) parameters
    """
    for neuron_id, replication_scores in judge_replications.items():
        # Fit GRM: score ~ latent_trait
        a_param, d_param = fit_grm(replication_scores, human_gold[neuron_id])
        
        # High 'a' (discrimination) = judge responds sharply to true differences
        # High 'd' (difficulty) = judge requires strong evidence before scoring high
        
        if a_param < 0.8:
            print(f"{neuron_id}: LOW DISCRIMINATION → rubric ambiguous, revise")
        if d_param > 2.0:
            print(f"{neuron_id}: HIGH DIFFICULTY → prompt too strict, soften anchors")
```

**Output:** Per-neuron diagnostics guiding rubric iteration (not a score change).

**Gate:** G-study must have ≥30 subjects × judge replications first

**Rung:** MEASURABLE (once G-study clears)

**Source:** 
- Tobin (1958) Tobit model
- IRT literature (Reedijk, van der Linden)
- Referenced paper: arxiv 2602.00521v2

**Migration:** None (analysis-only)

### **ITEM #4 — Active Learning Corpus Sampling**

**Integration Point:** §7 (annotation pipeline, corpus growth)  
**Files:** `calibration/active_learning.py` (new), `data/gold/` structure

**Current State:** Random addition of new gold chats; ad-hoc archetype spread

**Change:** Principled selection loop: uncertainty × diversity.

```python
def select_next_batch(existing_gold_set, unlabeled_pool, batch_size=5):
    """
    1. Compute annotation uncertainty from judge disagreement
    2. Cluster by embedding distance (diversity constraint)
    3. Select from under-represented archetype clusters
    4. Keep frozen anchor for drift detection
    """
    
    # Uncertainty: variance across judge replications
    uncertainties = {}
    for chat_id in unlabeled_pool:
        judge_scores = get_replicated_scores(chat_id)
        uncertainties[chat_id] = variance(judge_scores)
    
    # Diversity: embed and cluster
    embeddings = embed_transcripts(unlabeled_pool)
    clusters = clustering(embeddings, k=len(ARCHETYPE_TARGETS))
    
    # Select: high-uncertainty + under-represented archetype
    selected = []
    for archetype in ARCHETYPE_TARGETS:
        cluster = clusters[archetype]
        high_unc = sorted(cluster, key=lambda x: uncertainties[x], reverse=True)
        selected.extend(high_unc[:samples_per_archetype])
    
    return selected[:batch_size]
```

**What It Fixes:**

- Active learning makes growth schedule predictable and variance-efficient

### **ITEM #6 — Tobit Censored-EC Modeling**

**Integration Point:** §5.2 (EC dimension) + §8 (measurement)  
**Files:** `src/trait/extractors/per_dimension/ec.py`

**Current State:** EC scores are point estimates. Off-screen verification is not modeled.

**Problem:** Most verification happens off-transcript. EC scores masquerade as precise when they are **left-censored lower bounds**.

**Change:** Fit Tobit model to recover latent verification propensity.

```python
def fit_tobit_ec(session_transcripts, ec_observed_scores, telemetry):
    """
    Latent variable: verification_propensity (unobserved)
    Observed: ec_score (censored lower bound)
    
    Model: verification_propensity ~ [covariates]
           ec_score = max(0, verification_propensity) + measurement_error
    
    Output per user: 
      - point estimate (same as before)
      - lower CI (asymmetric, widens when off-screen evidence suspected)
      - upper CI (reflects censoring)
    """
    from scipy.optimize import minimize
    
    # LL = sum of censored + uncensored components
    def tobit_ll(params, ec_observed, X):
        mu = X @ params[:n_params]
        sigma = params[-1]
        
        censored_idx = ec_observed == 0  # No evidence in transcript
        uncensored_idx = ~censored_idx
        
        ll_censored = norm.logcdf(-mu[censored_idx] / sigma)
        ll_uncensored = norm.logpdf((ec_observed[uncensored_idx] - mu[uncensored_idx]) / sigma)
        
        return -(ll_censored.sum() + ll_uncensored.sum())
    
    result = minimize(tobit_ll, ...)
    return result.params, credible_intervals
```

**Output:** EC scores now carry honest uncertainty intervals that **widen when off-screen evidence is probable**.

**CRITICAL INTERACTION:** Deploy together with SSSR Phase 0 (Item #12, CSL upgrade). Both correct the same user class (Compressed Expert). See Cross-Integration § 2.1.

**Gate:** None (runs on existing EC data)

**Rung:** MEASURABLE

**Source:** Tobin (1958) Tobit model; censored observation literature

**Migration 016:** Add cols: `ec_censored_lower_bound (BOOL)`, `ec_latent_ci_lo (FLOAT)`, `ec_latent_ci_hi (FLOAT)`

```python
def conformance_check_session(session_id, observed_event_trace, expected_process_model):
    """
    Expected model (e.g., problem-solving):
      Frame → Generate → Verify → Integrate
    
    Observed trace: sequence of actual human/AI events
    
    Output: fitness score + deviations
    """
    from pm4py.algo.conformance import conformance_diagnoser
    
    fitness = conformance_diagnoser.apply(
        observed_event_trace,
        expected_process_model,
        variant="token-based"
    )
    
    deviations = [event for event in observed_event_trace 
                  if not is_consistent_with_model(event, expected_process_model)]
    
    return {
        'fitness_score': fitness,      # 0–1; 1 = perfect conformance
        'deviation_events': deviations,
        'mapped_regime': regime_overlay_label(deviations)
    }
```

### **ITEM #12 — Universal Baseline Layer (Behavioral Capability Specification)**

**Integration Point:** §3.7 (era/cohort schema) + §7.7a (Psychometric Maturation, Stage 4) + §10.3 (deferral register)

**THE CRITICAL DISTINCTION:** This is **NOT a norm-referenced percentile system** (forbidden by Commitment 12). It is a **conformance-based behavioral specification**.

#### **Architecture: Five Layers (Operationalized as Observable Neurons)**

| Layer | Definition | Observable Behaviors | Variation |
|---|---|---|---|
| **Biological** | Baseline cognitive infrastructure | Reading latency, WM-task accuracy, sustained attention | Minimal |
| **Educational** | Prerequisite knowledge/concepts | Domain knowledge extraction, recall accuracy, basic procedures | HIGH |
| **Domain** | Field-specific reasoning | Domain-specific error detection, professional heuristics, framework selection | HIGH |
| **Cognitive** | Reasoning & metacognition | Logical deduction, metacognitive calibration, self-correction, strategy selection | LOW-MEDIUM |
| **Interaction** | AI-literacy prerequisites | Ability to constrain problem, critique output, contextualize responses | MEDIUM-HIGH |

#### **Operationalization: Baseline Capability Specification (BCS) Checklist**

Example: Undergraduate, STEM, Year 2

```
KNOWLEDGE LAYER (Educational)
✓ Can perform basic algebra operations
✓ Can recall calculus fundamentals
✓ Can recognize common probability distributions
✓ Can identify algorithmic complexity notations

REASONING LAYER (Cognitive)
✓ Can decompose multi-step problems into subgoals
✓ Can follow multi-step logical arguments
✓ Can identify logical fallacies in reasoning
✓ Can evaluate evidence quality (basic level)

METACOGNITION LAYER (Cognitive)
✓ Can distinguish "I know this" from "I'm guessing"
✓ Can calibrate confidence in own answer
✓ Can explain reasoning to others
✓ Can identify when confused vs. when needs verification

DOMAIN LAYER (Domain)
✓ Can write syntactically correct code
✓ Can trace code execution mentally
✓ Can identify off-by-one errors
✓ Can apply standard design patterns

INTERACTION LAYER (Interaction)
✓ Can ask clarifying questions about ambiguous prompts
✓ Can identify if AI answer contradicts prior knowledge
✓ Can explain what the AI should focus on
✓ Can critique overly broad or narrow AI responses

MINIMUM PROOF TASKS
✓ Solve a moderately complex problem with 2+ steps
✓ Debug code with a specific error class
✓ Evaluate whether a solution fits constraints
```

#### **Session Conformance Checking (Not Ranking)**

```
User Archetype: Undergraduate, STEM, Year 2
Expected BCS items: 14/14

Observed in transcript:
✓ Decomposed problem
✓ Explained reasoning
✓ Identified API constraint error
✓ Asked clarifying question
~ Calibrated confidence (implied but not explicit)
✗ Did not critique AI answer for missing edge cases
✗ Did not verify correctness independently

Conformance Score: 10/14 = 71%

Interpretation: User shows expected foundational capabilities for Year 2.
Weak areas: independent verification, critical completeness evaluation.
```

**The Three-Level Comparison (No Mixing):**

```
LEVEL 1 — Personal Trajectory
  "This user's reasoning improved from 6/8 to 7/8 across sessions."
  (within-subject, no reference group)

LEVEL 2 — Stage Conformance  
  "Year 2 STEM students expected to show 12/14 BCS items;
   this user shows 10/14 (weak on verification)."
  (criterion-referenced, not norm-referenced)

LEVEL 3 — Stage Population Discovery
  "Across 80 Year-2 STEM students, 92% show reasoning capability,
   78% show independent verification, 65% show critical evaluation."
  (descriptive only — never prescriptive or ranked)
```

- Precision-not-multiplier invariant
- `csl/ownership.py` formula
- `src/merge/precision.py`
